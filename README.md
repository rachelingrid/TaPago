Tá Pago ✓
Controle de contas do mês para quem tem TDAH.
Fotografe o boleto, receba o lembrete, marque "tá pago".
O Tá Pago é um app que roda no navegador do celular, funciona sem internet e guarda tudo só no seu aparelho. Não há cadastro, servidor ou mensalidade. Ele é hospedado de graça pelo GitHub Pages.
Por que este app existe
Quem tem TDAH raramente esquece uma conta porque não sabe que ela existe. O que acontece é outra coisa: o boleto chega no WhatsApp e afunda na conversa, a conta fica "para depois" e o vencimento passa. O comprovante some, e no fim do mês ninguém sabe o que foi pago.
